# 스마트 발송 문구 (냉장고 레시피)

앱인토스 콘솔 > 마케팅 > 스마트 발송에 그대로 붙여넣어 사용하세요.
토스 UX 라이팅 원칙(해요체 · 능동적 말하기 · 한 줄로 말하기)에 맞춰 작성했고,
제목은 14자 내외, 본문은 30자 내외로 짧게 잡았어요. 콘솔에 등록할 때 실제 글자 수
제한을 한 번 더 확인해주세요.

## 1. 신규 유입 (첫 방문 유도)

| 구분 | 문구 |
|---|---|
| 제목 | 오늘 뭐 먹지 고민 끝! |
| 본문 | 냉장고 사진 한 장이면 AI가 레시피를 추천해드려요 |
| 발송 타이밍 | 오전 11시 ~ 오후 12시 (점심 메뉴 고민 시간) |

| 구분 | 문구 |
|---|---|
| 제목 | 냉장고 파먹기, 시작할까요? |
| 본문 | 사진만 찍으면 있는 재료로 만들 요리를 알려드려요 |
| 발송 타이밍 | 오후 5시 ~ 6시 (저녁 장보기 전) |

## 2. 리텐션 (재방문 유도, 3~7일 미접속자)

| 구분 | 문구 |
|---|---|
| 제목 | 냉장고 정리, 아직이죠? |
| 본문 | 오늘도 애매한 재료들 사진 찍고 레시피 받아보세요 |
| 발송 타이밍 | 오후 5시 ~ 6시 |

| 구분 | 문구 |
|---|---|
| 제목 | 이번 주 장보기 전에! |
| 본문 | 냉장고부터 확인하면 장보기 목록이 반으로 줄어요 |
| 발송 타이밍 | 주말 오전 10시 |

## 3. 저녁 메뉴 리마인드 (매일/평일 루틴 알림, 사전 동의 필요)

| 구분 | 문구 |
|---|---|
| 제목 | 저녁 메뉴 정할 시간이에요 |
| 본문 | 지금 냉장고 사진 찍으면 3초 만에 추천해드려요 |
| 발송 타이밍 | 오후 5시 30분 |

## 4. 광고 시청 리워드 유도

| 구분 | 문구 |
|---|---|
| 제목 | 레시피 더 보고 싶으세요? |
| 본문 | 짧은 광고 하나로 추천 레시피를 더 받을 수 있어요 |
| 발송 타이밍 | 결과 화면 체류 후 미전환 유저 대상 |

## 5. 장보기 전환 (쿠팡파트너스 클릭 유도)

| 구분 | 문구 |
|---|---|
| 제목 | 부족한 재료, 바로 채워요 |
| 본문 | 추천 레시피에 없는 재료만 쏙쏙 골라 담을 수 있어요 |
| 발송 타이밍 | 레시피 상세 조회 후 미구매 유저 대상 |

---

### 작성 원칙 메모
- 해요체 사용, 명령형/강요형 표현 지양 ("~하세요" 대신 "~해보세요", "~드려요")
- 이모지는 제목에 최대 1개, 남용하지 않기
- 과장·확정 표현("무조건", "100%") 금지 — 앱인토스 UX 라이팅/다크패턴 가이드 위반 소지
- 알림 재동의가 필요한 리마인드성 메시지는 `requestNotificationAgreement`로 사전 동의를 받은 사용자에게만 발송
