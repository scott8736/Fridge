# 스마트 발송 문구 (냉장고 레시피)

앱인토스 콘솔 > 마케팅 > 스마트 발송에 그대로 붙여넣어 사용하세요.
공식 규격([스마트 발송 가이드](https://developers-apps-in-toss.toss.im/guide/marketing/smart-message))에 맞춰
**제목 7자 이내, 본문 25자 이내(공백 포함)** 로 전부 맞췄어요. 아래 표의 글자수는 실제로 세어본 값이에요.

## 작성 규칙 (실제 스펙)
- 제목: 최대 7자, 동사가 아닌 명사형으로
- 본문: 최대 25자, 마침표로 끝맺기, 해요체(~요.)
- 본문에 "토스" 또는 "토스에서" 반드시 포함
- 변수(치환값)는 2자로 계산됨
- 금지: 업계 용어/밈/유행어, 특정 실명, "긴급!"·"역대급" 같은 과장, "놓치면 후회" 같은 불안 조장 표현
- 전부 **광고성(프로모션)** 메시지예요 — 사용자 수신 동의가 필요해요

## 1. 신규 유입

| 항목 | 내용 | 글자수 |
|---|---|---|
| 제목 | 냉장고레시피 | 6자 |
| 본문 | 토스에서 사진 한 장으로 레시피 받아요. | 22자 |
| 타겟/타이밍 | 신규 유입 유저, 오전 11시~낮 12시(점심 고민 시간) |

## 2. 리텐션 (3~7일 미접속자)

| 항목 | 내용 | 글자수 |
|---|---|---|
| 제목 | 냉장고파먹기 | 6자 |
| 본문 | 토스에서 오늘 냉장고 재료 확인해봐요. | 21자 |
| 타겟/타이밍 | 이탈 유저, 오후 5~6시(저녁 장보기 전) |

## 3. 저녁 메뉴 리마인드 (사전 동의자 대상 루틴 알림)

| 항목 | 내용 | 글자수 |
|---|---|---|
| 제목 | 오늘저녁메뉴 | 6자 |
| 본문 | 토스에서 오늘 저녁메뉴 추천받아요. | 19자 |
| 타겟/타이밍 | `requestNotificationAgreement`로 사전 동의한 유저만, 오후 5시 30분 |

## 4. 보상형 광고 시청 유도

| 항목 | 내용 | 글자수 |
|---|---|---|
| 제목 | 레시피더보기 | 6자 |
| 본문 | 토스에서 광고보고 레시피 더 받아요. | 20자 |
| 타겟/타이밍 | 결과 화면 체류 후 보상형 광고 미시청 유저 |

## 5. 재료 구매 전환 (쿠팡파트너스 유도)

| 항목 | 내용 | 글자수 |
|---|---|---|
| 제목 | 재료채우기 | 5자 |
| 본문 | 토스에서 부족한 재료 바로 구매해요. | 20자 |
| 타겟/타이밍 | 레시피 상세 조회 후 구매 링크 미클릭 유저 |

---

### 발송 방법
- **직접 API**: 파트너 서버(우리 Cloudflare Worker)에서 직접 발송 API를 호출해 제어
- **토스에 요청**: 콘솔에서 1회성 또는 반복(매일/매주) 스케줄로 요청

### 참고
- 이 문구들은 전부 광고성(프로모션)이라 수신 동의한 유저에게만 발송돼요.
- 3번(저녁 메뉴 리마인드)처럼 반복 알림은 반드시 별도 동의(`requestNotificationAgreement`)를 먼저 받은 유저에게만 보내주세요.
